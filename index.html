→ 画面下の「▶ 1000人のあなたを走らせる」を押すと、いつでも結果が見られます

この数字は目安です。条件や行動を変えたときに「どれくらい変わるか」を比べるためのものです。前提を見る
  • すでに恋人や配偶者がいる人は対象から除き、一度付き合ったら別れないものとします。付き合ってから結婚するまでは、平均で約4.3年です（出生動向基本調査 2021）。
  • どの相手とも、関係は0から作るものとします。すでに知っている人も新しく出会う人に含めてかまいません。（成功率は絶対的なものではありません）
  • モデルはユーザーの主観的な入力に依存しており、ユーザーの行動傾向を可視化するための一つの指標にすぎません。（実際の恋愛の複雑な要素は含まれていません。）
  • 条件一致度は各項目を独立と仮定しており、周りの反対や、他の人に奪われるといった事象は考えないものとします。
  • 上達と疲弊は単純化された関数で表現しており、実際の人間の心理変化を完全に再現するものではありません。

      How it works

      しくみ

      数式を知らなくても大丈夫。やっていることは「人数を順番にしぼっていく」だけです。

      かんたんに言うと

      1. 期限までに、相手のいない人に何人会えるか1週間に会える人数 × 期限までの週数です。恋人や配偶者のいない人だけを数えます（すでに知っている人も含めてOK）。週3人なら、48日で約21人。
      2. そのうち、あなたの条件に合う人は何人か「身長175cm以上」なら男性の約4人に1人、のように、条件ごとの割合を掛けてしぼります。条件を増やすほど、人数は減ります。
      3. そのうち、恋愛に発展しそうな関係になる人は何人か関係は0から作るものとして、会った人のうち「いい感じ」まで進む割合を掛けます。
      4. そのうち、あなたを好きになってくれる人は何人か「10人中何人くらい好きになってくれそうか」というあなたの見積もりを掛けます。
      5. そのうち、期限までに付き合える人は何人か付き合うまでにかかる日数と、慣れ・疲れを考えます。期限の直前に出会った人とは、付き合うのが間に合いません。
      6. 最後に残った人数から、「少なくとも1人と付き合える確率」を出す残りが平均0.2人なら、5回に1回くらい1人と付き合える、というイメージで約18%です。
      ポイント：最後の人数が1人より少なくても、0%ではありません。「何回もやり直したら、何回に1回うまくいくか」が確率です。
      数式と前提をくわしく見る
      01 — OVERVIEW

      全体の式

      恋愛を「出会いという試行の積み重ね」と見ます。i 回目のチャンス（恋愛に発展しそうな出会い）がうまくいき、しかも期限までに付き合える確率を q(i) とします。

      q(i) = Pfits · Plikes · G(i) · F(i) · W(ti)
      記号意味決め方
      P_fits相手があなたの条件を満たす確率条件から計算（02）
      P_likes相手があなたを好きになってくれる確率あなたの見積もり（03）
      G(i)慣れによる上達上達度 g・上達スピード κ（05）
      F(i)会い続けることによる疲れ疲弊度 λ・行動量 r（05）
      W(t_i)期限までに付き合い始められる確率付き合うまでの日数 m・期限（06）

      期限までのチャンスの数を Neff（04）とすると、少なくとも1回うまくいく確率が最終成功率です。

      P = 1 − ∏i=1Neff ( 1 − q(i) )

      「全部うまくいかない確率」を1から引いています。q が小さいときは、P ≈ 1 − e−Σq（Σq = 最後に残る平均人数）です。

      02 — CONDITIONS

      条件を満たす確率 Pfits

      条件はユーザー自身が入力します。種類によって確率の出し方を変えています。

      身長・年収 → 分布の面積

      P(X ≥ a) = 1 − Φ( (a − μ) / σ )

      Φ：標準正規分布の累積分布関数。年収は対数正規分布（ln X が正規分布）で同様に計算します。

      例：男性の身長を μ = 171.5 cm、σ = 5.5 cm とすると、180 cm 以上は 1 − Φ(1.55) ≈ 6%。

      年齢 → 独身の人の年齢構成の中で範囲に入る割合

      結婚相手を探すので、独身の人だけで数えます。年齢ごとの人口（概算）に、令和2年国勢調査の年齢別未婚率（たとえば30〜34歳の男性51.8%・女性38.5%）をかけた構成の中で、選んだ年齢幅に入る人の割合です。

      よく挙がる条件の数字

      国立社会保障・人口問題研究所「第16回出生動向基本調査」（2021年）で、結婚したい18〜34歳の未婚者が、結婚相手の条件として「重視する」「考慮する」と答えた割合です。

      統計がある条件

      タバコを吸わない：令和4年 国民健康・栄養調査（喫煙する人は男性24.8%・女性6.2%）。大卒以上：内閣府男女共同参画局の調査の割付値をもとにした概数。結婚相談所の人数：IBJの会員数110,482名（2026年7月）・男女比 男54%女46%（IBJ発表）。

      数値にしにくい条件 → こだわり度

      「こだわらない（全員OK）」から「絶対ゆずれない（100人に1人）」まで6段階で選びます。「気にする（10人中3人がOK）」なら 0.3 です。

      年齢 → ふだん会う人の中での割合

      大学にいれば会う人のほとんどが同年代のように、年齢は環境で大きく変わるため、「ふだん会う人のうち、この年齢の人は10人中何人か」で入れます。全国の人口構成で計算することもできます。

      まとめ方

      Pfits = ∏k Pk
      例：上位90%・上位50%・上位20% の3条件なら　0.9 × 0.5 × 0.2 = 0.09（9%）
      03 — BEING LIKED

      好きになってくれる確率 Plikes

      条件に合う人と仲良くなっても、相手があなたを好きにならなければ付き合えません。そこで「条件に合う人と仲良くなったとき、その人があなたを好きになってくれる確率」を、あなた自身の見積もりとして入れます。

      Plikes = （10人中 n 人） = n / 10

      本当の値は誰にもわかりません。高く見積もるほど結果も高くなります。自己評価を変えて、結果がどう動くかを試すのも一つの使い方です。

      04 — CHANCES

      チャンスの数と、それがいつ来るか

      • 行動量 r：恋人や配偶者のいない人に、1週間で会える人数（すでに知っている人も含む）
      • 期間 T：今日から期限の日までの日数
      • 関係進展速度 krel：会った人のうち、恋愛に発展しそうな関係まで進む割合（関係は0から作る）
      Neff = ⌊ r · ( T / 7 ) · krel ⌋　　　ti = 7i / ( r · krel )

      ti：i 回目のチャンスが来る日（今日から何日後か）。チャンスは一定のペースで来るとします。

      05 — GROWTH & FATIGUE

      慣れ G(i) と疲れ F(i)

      慣れ：経験を積むほど上手くなるが、いずれ頭打ち

      G(i) = 1 + g · i / ( i + 1/κ )

      最初は1に近く、だんだん 1+g に近づきます。g：最大の伸び　κ：慣れる速さ

      疲れ：会うペースが速いほど、1回ごとの質が下がる

      F = 1 / ( 1 + λ · r )

      λ：疲れやすさ　r：ペース（人/週）。ペースを上げると1回ごとの質は下がりますが、会う回数がそれ以上に増えるので、行動すれば結果は上がります。

      06 — DEADLINE

      期限までに付き合える確率 W

      仲良くなってから付き合うまでの日数を、平均 m 日の指数分布とします。ti 日後に出会った相手と、残り R = T − ti 日のうちに付き合い始められる確率は

      W(R) = 1 − e−R / m

      早く出会うほど1に近く、期限の直前に出会うと0に近づきます。付き合い始めたカップルは別れないものとします。

      08 — ASSUMPTIONS

      前提と限界

      • 好かれる確率は自己評価：結果はこの値にほぼ比例して変わります。
      • 相手のいない人だけを数える：恋人や配偶者がいる人は最初から除いています。すでに知っている人も含めてよく、関係は0から作るものとします。
      • カップルは別れない：付き合い始めたら、期限まで続くものとしています。
      • 条件どうしは独立：実際は年収と学歴などに相関があり、掛け算だと確率を小さく出しすぎます。
      • チャンスどうしは独立：1人と仲良くなっている間は次の出会いが減る、といった制約は入れていません。
      • 式の形は仮定：慣れ・疲れ・付き合うまでの日数の式は、直感に合う形として選んだもので、データで検証したものではありません。
      • Neff は切り捨て：チャンスが1回未満なら0回として扱います。
      • 分布は概算：身長・年収・年齢の値は目安です。
